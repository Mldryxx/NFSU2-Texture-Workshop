PANDUAN PENGGUNA

How To · Texture Workshop

1. Buka file BIN

Tekan Pilih file BIN, lalu cari arsip mobil (.BIN atau .TPK) dari penyimpanan. File original tidak ditimpa.

2. Pilih tekstur di Texture Browser

Ketuk item tekstur dalam daftar untuk melihat preview, nama, dan ukuran. Pastikan target yang dipilih benar sebelum mengganti.

3. Penggantian tekstur biasa (DDS)

Pilih tekstur target, tekan Import DDS, lalu pilih file DDS dengan ukuran yang sesuai. Gunakan untuk tekstur yang tidak membutuhkan pasangan Base + Mask.

4. Mengatur pasangan Base + Mask
  1. Pilih tekstur Base di daftar, tekan Jadikan Base.
  2. Pilih tekstur Mask pasangannya, tekan Jadikan Mask.
  3. Tekan Pilih DDS Base dan pilih file Base dari HP.
  4. Tekan Pilih DDS Mask dan pilih file Mask.
  5. Periksa nama file lalu tekan Terapkan pasangan.

Bedanya: “Jadikan Base/Mask” menentukan target tekstur dari daftar. “Pilih DDS Base/Mask” memilih file pengganti dari penyimpanan HP.

5. Penggantian vinyl (Mask + DDS)

Untuk vinyl, pilih texture target dan import file Mask + DDS pengganti yang sudah tersedia, lalu terapkan pasangan. Tidak perlu menjalankan Color Separation atau mengatur jumlah warna di Workshop.

7. Simpan hasil BIN

Tekan Simpan BIN sebagai… dan simpan dengan nama baru. Hindari menimpa file original agar mudah kembali jika hasil mod bermasalah.
